# MGS2 AP location catalog

Every location the AP patch knows, by area in rough story order. Tick each one as you
pick it up. On the patched game every world spot below shows its vanilla model but
gives a **Razor**. A real item from a world spot means a spot the patch missed.

Tags: **STORY-LOCKED** = only during a story window (must be filler only in the apworld);
**NEW** = patched, but not in the apworld yet; **FIGHT** = boss-fight drop;
**backup** = vanilla only spawned it if you didn't hold the item (patched: always there).

- Boss-fight supplies, drops and re-drops: Fortune (Sea Dock), Fatman (Heliport, story 0x76: 3 SOCOM Ammo, M9 Ammo, Ration), Vamp (Shell 2 Filtration Chamber 2, before story 0x101: M9 Ammo, RGB6 Ammo, SOCOM Ammo, Ration, M4 / M4 Ammo), Vamp and Emma (Strut L: Pentazemin, PSG1 ammo).
- Harrier fight (Shell 1-2 bridge): the Stinger Ammo next to the Stinger, every load.
- Shell 1 Core B2: the Books that drop off the top of a locker (one per load, chained; no save byte).
- Shell 2 Filtration Chamber 1: the Grenade (the game spawns it off the map; unreachable).
- Shell 2 Filtration Chamber 2 (Vamp fight room): M4 / M4 Ammo and a Ration beside the fight supplies.
- EF Connecting Bridge: the Claymores you pick up off the bridge.
- Guard drops (ammo, Rations from knocked-out or killed guards).
